# Anglesey guide

Astro static site for family things to do on Anglesey. Hosted on Vercel; merging to `main` deploys production, so all changes go through a pull request.

- File format and fields: [CONTRIBUTING.md](CONTRIBUTING.md)
- Writing or researching place content: [docs/content-guide.md](docs/content-guide.md). Follow it for any generated text.
- Before opening a PR: `npm run check` and `npm run build` (Node version in `.nvmrc`).
